- **[World Cup Story Mode](https://github.com/YoPerry007/world-cup-story-mode)** — An interactive sports-history experience combining Next.js, editorial design, structured data, Supabase, and automated testing.

My work also includes native Android applications, education and administrative systems, interactive interfaces, motion graphics, and original code-driven films. Selected source repositories are public; other product work is represented through my portfolio.
