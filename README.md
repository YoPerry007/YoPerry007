## Product work

- **[Offscript](https://ekowperryportfolio.netlify.app/work/offscript)** — I designed and built a speaking coach that turns a recording into feedback a speaker can use in the next attempt. I built the browser recording, transcription, feedback and practice history. I also implemented recovery that can reuse the uploaded take if analysis is interrupted. [Try Offscript](https://thetribeland.com/).
- **[Stocka](https://ekowperryportfolio.netlify.app/work/stocka)** · In development — An Android-first sales and inventory app for Ghanaian retailers. I built the offline sales flow so a sale and its stock changes are saved together on the device. When the connection returns, the app can retry syncing without recording the sale twice.
- **[Fleet operations platform](https://ekowperryportfolio.netlify.app/work/fleet)** · In development — I worked across the management web app and the driver app, including fleet assignments, trips, and maintenance. I implemented permissions that limit what staff can see and change, and tested the handoffs from service work through cost review.
- **[Project Ananse](https://ekowperryportfolio.netlify.app/work/ananse)** · In development — A web and mobile learning platform for Ghana's curriculum. I built curriculum authoring, independent review and publication tied to exact lesson and file revisions. In an isolated test restore with synthetic data, I verified that withdrawn files stayed out of the learner library.
- **[IHearVoices](https://ekowperryportfolio.netlify.app/work/ihearvoices)** — A voice-enabled mobile marketplace. I built customer, seller, and admin workflows around a shared checkout that gives each seller access to their own portion of an order, with Paystack payment verification on the server. [Source](https://github.com/YoPerry007/IHearVoices-Ecommerce---YouTube).
- **[GSE Corporate Actions Crawler](https://github.com/YoPerry007/gse-corporate-actions-crawler)** — A Python service that turns Ghana Stock Exchange announcements into dividend and meeting records. It avoids duplicates on repeat runs and flags incomplete records for review.
